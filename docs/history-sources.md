# History sources — New Carthage, 221 BCE

Every in-game fact links to a row here. Status: **sourced** (cited), **disputed** (sources disagree), **invented** (labeled fiction in-game).
Verified = I read the cited text/page this session (2026-10-17). Secondary = only reported by a search summary; re-check before shipping.
