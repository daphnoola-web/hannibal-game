# History spine, 221–202 BCE

One page per chapter-level event: what happened, where the ancient text says so, and how sure we are.
Written in S2 (2026-10-19). Extends `history-sources.md` (the per-fact table used by in-game cards).

**Reading status key**
- **read** = I fetched the ancient text this session (Polybius: Thayer/LacusCurtius English; Livy: Latin on thelatinlibrary.com) and the point below is a paraphrase of that passage. The fetch tool summarises long pages, so **section numbers and numbers must still be re-checked against the text before any in-game card says "verified"** (rule 15; you do the final read).
- **date from general knowledge** = the year is the standard scholarly date but was not in the fetched passage.
- **TODO** = not read yet; do not use in the game until read.

Numbers (losses, army sizes) differ between sources; the game should say "reported" and give a range or both figures.
